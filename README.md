# Jacob Herbstman's academic website

Published at https://jacobherbstman.github.io/ using GitHub Pages.

The site is plain HTML and CSS. Edit `index.html`, `research.html`, or
`teaching.html` to update the corresponding page. PDF downloads are in `files/`.

GitHub Pages publishes the root of the `main` branch. The `.nojekyll` file keeps
the site buildless. Push updates to `main` to publish them.
